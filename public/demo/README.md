# STAR ORBIT · 星际漫游

原创、可直接运行的 Game Boy Advance 自制小游戏。驾驶飞船在星空中收集金色信标，体验按键、声音、暂停、倍速和即时存档。ROM 不包含任何商业游戏内容。

| GBA 按键 | 操作 |
| --- | --- |
| 十字键 | 移动飞船 |
| A（按住） | 推进加速 |
| B | 发出脉冲，可收集附近的信标 |
| START | 重置游戏与计分，同时更新电池存档 |

移动到金色信标旁即可收集；右上角显示收集数，达到 99 后循环。收集与脉冲会播放短音效。游戏没有失败条件，适合自由试玩。

## 重新生成

在项目根目录运行：

```sh
node scripts/create-demo.mjs
```

脚本仅使用 Node.js 内置模块，无需 ARM 编译器。输出 `star-orbit.gba` 及调试用符号表。它生成 ARMv4T 指令、GBA 启动头、原创位图字体和图形，使用 IWRAM 执行代码、Mode 4 双缓冲画面、GBA 原生按键寄存器与 PSG 音效。因此演示运行在真实模拟器核心中，而非网页动画。

收集数通过 SRAM 电池存档保存，下次启动会恢复；飞船位置与脉冲等完整现场可通过模拟器的即时存档保存。电池存档包含魔数、版本与校验，空白或损坏存档会安全初始化。源码与原创内容按 MIT 授权，详见 [LICENSE.txt](LICENSE.txt)。GBA 标准启动识别字节仅用于硬件兼容。
