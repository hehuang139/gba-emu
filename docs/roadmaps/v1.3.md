# v1.3：可控离线应用壳与资源完整性

本阶段把已验证的 GBA 应用壳做成可安装、可离线运行且可控升级的资源包。Service Worker 只缓存同一构建版本的应用资源与核心文件，不删除 IndexedDB 游戏库或存档。

## 已完成

- [x] 添加 Web App Manifest 与版本化 Service Worker 缓存。
- [x] 首次联网后缓存应用壳、字体、核心 JavaScript / WebAssembly 与静态资源。
- [x] 离线导航回退到已缓存应用，并保留 COOP / COEP 响应头。
- [x] 新版本等待用户操作后切换；运行中的页面不会自动刷新。
- [x] 显示在线、离线、本地缓存和更新状态。
- [x] CI 校验随仓库分发的 mGBA WebAssembly SHA-256。
- [x] Playwright 覆盖 manifest、Service Worker 控制、缓存和断网刷新。

## 验证边界

`pnpm test:pwa` 已在 Edge 141 / Windows 通过，远端 CI 负责 Linux Chromium 复测。PWA 的真实安装体验、Safari/iOS、Android、安全区、低内存设备和长期离线压力仍需实机验收。Service Worker 不改变 mGBA 版本、即时存档格式或 IndexedDB 数据。
